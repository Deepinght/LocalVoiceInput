# V0.2 交互增强范围

本文件是 2026-10-01 确认的修改范围。原 V0.1 基线保留为历史文件；关于默认按住说话、禁止可选直接上屏等旧规定，由本次需求覆盖。

## 实现

1. 单击快捷键开始/结束，设置中保留按住说话。
2. 小型可拖动控制条，不抢焦点，含开始/结束、取消、置顶、设置、收起。
3. 显示空闲、录音、识别、审阅、提交、模型状态；录音计时、识别等待计时和真实音量。
4. 开始、结束、失败提示音，可关闭。
5. 候选字号 12～36 pt，A−/A+ 与数值调整；原文小两号，持久化保存。
6. 控制条和候选窗口独立置顶并保存。
7. 审阅/直接上屏两种模式，默认审阅；控制条醒目显示并允许空闲时切换。
8. 复制候选、使用原始识别、恢复处理结果。
9. 常见错误通过控制条/托盘提示，保留设置入口；上屏失败保留候选可复制。
10. 将公共词典、测试和文档的专属项目内容替换为通用示例，并为 GitHub 源码准备空白模板与排除规则。

## 本版范围之外

会议转写、静音自动结束、显示目标名称、按应用保存输出方式、重新录音、自动撤销、复杂历史管理、多显示器位置恢复和首次使用向导。

最大录音时间继续为 120 秒。窗口位置本次不做跨次记忆；字号和置顶状态保存。原文和处理轨迹保持可查看，默认仍不保存录音。
