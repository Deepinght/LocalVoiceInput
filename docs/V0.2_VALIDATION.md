# V0.2 验证记录

验证日期：2026-10-01。平台：Windows x64；在既有 V0.1 可用版本上更新交互，ASR 模型不变。

## 自动验证

`python -m pytest -q`：**50 passed**。

覆盖新增交互的重要分支：

- 单击模式松开键不停止，再按一次才停止；按住模式仍在释放后停止。
- 录音取消不识别、不输出；识别期间取消后，后台返回的结果被丢弃，且不并发启动新录音。
- 审阅模式未确认不输出，取消不输出；确认只发送编辑后的文本一次，并记录正确历史状态。
- 直接模式必须明确设置，成功时不弹候选；目标切换或输出失败时保留可复制候选，不自动重试。
- 空识别不输出，字号调整不改变文字，使用原文/恢复处理结果不改变 raw_text。
- 字号、置顶、上屏模式持久化；旧配置补充单击模式和默认审阅等安全默认值。
- 公共源码导出排除用户文件、历史、日志、构建目录、模型、发布包与私有备份；空白模板能从干净目录初始化用户文件且不覆盖已有修改。

原有词典、Pipeline、Lua、学习、历史、配置回滚、输出失败保护测试继续通过。

另将公共源码 ZIP 解压到独立目录，在不携带本机用户配置的情况下再次运行测试：**50 passed**，确认源码包自身包含运行测试所需的通用模板与资源。

## 发布与数据边界

- V0.2 目录独立生成，保留本机旧版供对照；未中止旧版正在运行的进程。
- 可执行程序不含模型。源码包按白名单导出，不依赖本机 `.venv` 或个人配置。
- 内置词典和全部公开示例已改为通用内容。旧版原始需求仅作为本地私有备份保留，不进入源码包或发布包。
- 已修改的用户词典与纠错记录仍属于本机数据，未导出。仅当词典与旧版出厂文件完全相同时，升级才自动替换为新版通用词典。
- 没有执行 GitHub 上传、创建仓库或发布 Release。

## 使用者仍需确认

自动测试已覆盖逻辑分支，Windows 独立测试窗口已验证输出及焦点，但没有代替使用者在 Word、浏览器、VS Code 等日常软件中完成新交互的逐项口述验收。提示音的主观音量也需按实际设备感受；可在设置中关闭。

建议先退出旧版，再启动新版：测试单击开始/结束、Esc 取消、字号保存，以及审阅/直接两种上屏模式。若应用不接收标准输入，可在设置里改用“剪贴板粘贴”。
